# News_Portal_Automation
# 📰 Online Khabar News Portal Automation

Automated testing and scraping framework designed for **Online Khabar** ([onlinekhabar.com](https://www.onlinekhabar.com/)) — *No. 1 News Portal from Nepal in Nepali*.

---

## 📌 About the Project

This project provides an automated end-to-end testing suite / web crawler for Nepal's leading Nepali news portal, **Online Khabar**. It validates website functionality, tests user interactions, and verifies news content structure across desktop and mobile views.

### Key Features
* 🧪 **End-to-End Automation:** Automated test scripts for key user journeys (Homepage, Category navigation, Article detail pages, Search).
* 🇳🇵 **Nepali Unicode & Content Verification:** Ensures elements containing Nepali text render correctly without missing UI components or broken fonts.
* 📱 **Responsive Viewport Testing:** Cross-browser and responsive web design testing across multiple device viewports.
* 📊 **Test Reporting:** Generates detailed execution reports with log tracking and screenshot capturing upon test failure.
